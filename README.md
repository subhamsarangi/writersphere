## 🌟 Features

### Mindful Writing Experience

**Breathing Exercise**
- Start each writing session with a calming 30 or 60-second breathing exercise
- Smooth animations guide you through inhale, hold, and exhale cycles
- Appears once per hour to maintain focus without interruption
- Helps clear your mind before you begin creating

**Distraction-Free Editor**
- Clean, minimal interface that keeps you focused on your words
- Rich markdown support with live preview
- Auto-save so you never lose your work
- Dark and light themes for comfortable reading and writing

**Poetry Mode**
- Articles tagged as "poetry" get special typographic treatment
- Elegant Avenir font for a refined reading experience
- Optimized spacing and formatting for verse

### Content Organization

**Flexible Structure**
- Organize articles with categories and subcategories
- Tag your work for easy discovery
- Multiple status options: Draft, Published, Unpublished, Archived
- Visual status indicators with color-coded badges

**Smart Search**
- Find articles quickly with full-text search
- Filter by status, category, or subcategory
- Browse all published content in the public feed

### Public Reading Experience

**Beautiful Article Pages**
- Clean, readable typography optimized for long-form content
- Theme toggle for reader preference (dark/light)
- Author attribution and publication dates
- Tag display for content discovery

**Article Feed**
- Browse all published articles with infinite scroll
- Search across titles and content
- See tags at a glance
- Responsive design for any device

### Dashboard & Management

**Article Management**
- View all your articles in one place
- Filter and search to find what you need
- Quick status changes and editing
- Bulk organization with categories and tags

**Category System**
- Create hierarchical content structures
- Add images to categories and subcategories
- Activate or deactivate as needed
- Visual organization tools

**Tag Management**
- Create and manage content tags
- See tag usage across articles
- Organize your content taxonomy

### User Experience

**Responsive Design**
- Works beautifully on desktop, tablet, and mobile
- Floating navigation on mobile for easy access
- Adaptive layouts that fit any screen

**Smooth Interactions**
- Elegant animations and transitions
- Wave boundaries for visual polish
- Loading states that keep you informed
- Instant feedback on all actions

**Reliable Performance**
- Connection monitoring alerts you to network issues
- Helpful guidance when things go wrong
- Fast page loads and smooth navigation

## 🚀 Getting Started

### Prerequisites

- Node.js 20 or higher
- A Supabase account
- npm or yarn

### Quick Start

1. **Clone and install**
   ```bash
   git clone https://github.com/yourusername/writersphere.git
   cd writersphere
   npm install
   ```

2. **Configure environment**
   
   Create `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

3. **Set up database**
   
   Run the SQL scripts in `meta-guide/` folder in your Supabase SQL editor

4. **Start developing**
   ```bash
   npm run dev
   ```

5. **Open http://localhost:3000**

### Deploy to Production

```bash
npm run build
npm start
```

Or deploy to Vercel with one click.

## 🎯 Design Philosophy

Writersphere is built around these core principles:

**Mindfulness First**
Writing is a creative act that deserves intention. The breathing exercise helps you arrive at the page with clarity and focus.

**Distraction-Free**
Every design choice removes friction between you and your words. No clutter, no unnecessary features, just what you need to write well.

**Beautiful by Default**
Good design isn't decoration—it's clarity. Clean typography, thoughtful spacing, and smooth interactions make writing a pleasure.

**Flexible Organization**
Your content is unique. Categories, subcategories, and tags give you the structure you need without imposing rigid hierarchies.

**Reader-Focused**
Published articles are optimized for reading. Theme options, clean layouts, and responsive design ensure your words reach readers beautifully.

## ✨ What Makes Writersphere Different

**It Respects Your Process**
The breathing exercise isn't a gimmick—it's a recognition that good writing starts with a clear mind. Take a moment, breathe, then create.

**It Gets Out of Your Way**
No complex menus, no feature bloat. Just a clean editor, smart organization, and the tools you actually need.

**It Makes Your Work Shine**
Published articles look professional and polished. Your readers see your best work in the best light.

**It Grows With You**
Start with simple drafts. Add categories as you need them. Tag for discovery. The system adapts to your workflow, not the other way around.
